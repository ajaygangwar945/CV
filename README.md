## 🚀 Overview

Welcome to my interactive CV portfolio! This project is a modern, responsive web page built to showcase my core competence and academic background in a visually stunning way.

Instead of a boring list of links, this portfolio utilizes a highly interactive **3D glassmorphic card design** with an integrated in-page PDF viewer.

## ✨ Features

- **3D Card Interactions:** Hovering over the CV cards creates an immersive 3D tilt effect using `VanillaTilt.js`.
- **Dynamic Neon Styling:** A premium dark-mode aesthetic featuring glowing abstract background blobs.
- **Glassmorphism UI:** Frosted-glass design trends implemented with purely CSS `backdrop-filter`.
- **In-Page Document Viewer:** Click "View" to instantly open the CV in a custom animated modal without leaving the website or downloading external files.
- **Fully Responsive:** Gracefully degrades and reorganizes layout for seamless viewing on mobile and tablet devices.

## 🛠️ Usage

To run this project locally, you don't need any complex build tools. Since it relies purely on standard web technologies:

1. Clone or download this repository.
2. Open the directory containing the files.
3. Simply double-click on `index.html` to open it in any modern web browser.

## 📂 Project Structure

```text
📁 CV Portfolio
├── 📄 index.html                       # Main HTML structure and modal
├── 📄 styles.css                       # Advanced CSS (glassmorphism, animations, responsive design)
├── 📄 script.js                        # Interactions (VanillaTilt init, custom mouse-tracking glow, modal logic)
├── 📄 favicon.png                      # Modern 3D document icon
├── 📄 Ajay Gangwar CV.pdf              # Comprehensive resume
```
